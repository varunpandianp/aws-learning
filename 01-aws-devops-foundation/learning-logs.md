### 🧠 What I Learned

- Before cloud computing, organizations mainly used **traditional on-premises infrastructure**.
- Traditional infrastructure required companies to purchase and maintain physical servers, networking, storage, data centers, power and cooling.
- Traditional infrastructure had problems such as **high upfront cost, slow provisioning, resource underutilization, difficult scaling and hardware maintenance**.
- A **database is an organized collection of data** used by applications to store, retrieve and manage information.
- A **physical server** is a real hardware machine containing CPU, RAM, storage and networking resources.
- **Virtualization** allows physical hardware resources to be used to create multiple virtual machines.
- A **hypervisor** allows multiple virtual machines to run on a single physical server.
- Hypervisors improve **resource utilization, flexibility and isolation**.
- **Cloud computing** provides computing resources on demand over a network.
- **AWS** is a cloud computing platform that provides services such as compute, storage, networking, databases, security and monitoring.
- Cloud computing helps reduce the need for large upfront infrastructure investments.
- Cloud resources can be provisioned and scaled much faster than traditional physical infrastructure.
- AWS provides infrastructure across **Regions and Availability Zones**.
- Cloud computing can support high availability, scalability, automation and disaster recovery architectures.
- **CAPEX** refers to upfront capital expenditure, while **OPEX** refers to ongoing operational expenditure.
- The infrastructure evolution can be understood as:

  **Physical Infrastructure → Virtualization → Cloud Computing → Automation → DevOps**

→ Flexible Scaling

### 💡 Important Understanding

The main reason organizations moved toward cloud computing was to overcome many limitations of traditional infrastructure.

Cloud computing provides:

- On-demand resources
- Faster provisioning
- Flexible scaling
- Global infrastructure
- Managed services
- Automation
- High availability options
- Disaster recovery options
